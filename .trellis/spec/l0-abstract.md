## 一、正文一：通用铁律 R-01~R-24

- **R-01 零臆测 + 检索先行双通道**：非百分百确证的技术事实严禁脑补，动手前先走 WebSearch/WebFetch 与 GitHub API 双通道检索，按名字精确探测，绝不扩大为全盘盲搜。
- **R-02 全中文思维链与全中文产出**：一切思考、推导、回复、文档、注释、汇报必须 100% 中文，仅代码标识符、命令输出、专有名词例外，违反即重做。
- **R-03 单命令 ≤10 秒硬死线**：任何命令前台运行绝对禁止超 10 秒，超时即判定失败并立即降级（限定路径/减小深度/分片/转后台），严禁原样重试。
- **R-04 非阻塞全并行、长任务后台化**：互相独立的调用同一轮次一次性并发发出，构建/装包/大测试/全盘扫描/打包等长任务一律后台化，拿句柄立即返回。
- **R-05 禁等待型命令与禁无界递归全盘扫描**：禁 sleep/timeout/tail -f/ping -t/轮询循环，禁全盘 find/grep -r/Get-ChildItem -Recurse，须限定目录加深度加分片或改用索引工具。
- **R-06 强制 diff 工具、禁终端写源码**：代码与配置变更一律用局部块级 diff 编辑，禁重定向、cat<<EOF、node -e、python -c 直接写源码，改动须透明可审查可回滚。
- **R-07 全程出声**：每次工具调用前文字报备做什么/看到什么/下一步，写配置前报绝对路径加内容加原因，写完立刻读回校验，宁可不改也不静默改。
- **R-08 交互问答聚合提问、重大决策主人裁定**：需求不明或有权衡时用问答工具一次聚合多问，架构取舍/重构/大范围删除/依赖选型等列利弊与推荐项，等主人拍板再动手。
- **R-09 计划先行、PRD 不留 TBD、复选框实时勾选**：任务前先完善 prd.md，验收标准不得 TBD，implement.md 复选框随执行实时勾选，严禁实施跑在计划前。
- **R-10 可选后端适配器**：纯前端引入服务端能力走「适配器 + 特性检测 + 静默降级」，后端不可用时纯前端主路径全功能闭环，核心层不感知后端存在。
- **R-11 高风险操作显式授权门禁**：删除或覆盖文件、安装依赖、大重构或分支清理、意图歧义四类操作前必须显式报备并取得主人授权。
- **R-12 凭据脱敏、密钥外置、日志禁记敏感值**：交付物零凭据零隐私零真实数据，key/token/secret 一律「前 8 字符 + 已脱敏」，密钥只存环境变量或外置文件，禁硬编码、禁回显、禁写日志。
- **R-13 前端零 CDN、单文件、file:// 兼容**：禁 CDN 样式与远程脚本，资产本地离线自包含，HTML 原型单文件，严格兼容本地 file:// 协议，grep 门禁验证运行时零外链。
- **R-14 UI 文本产品化、禁元文本**：界面面向最终用户，禁实现说明/设计思路/TODO/免责小字等元文本，文案短、准、面向动作，长说明收敛到 tooltip。
- **R-15 禁 AI slop 套路、设计技能链、真实浏览器截图自检**：写界面前先调设计技能，无稿先搜同类顶级站点并用 chrome-devtools 截图提取设计系统，禁 Inter/紫蓝渐变/等距三栏等套路，交付前真实截图自检。
- **R-16 禁内置预览通道**：禁 IDE 内置 preview/screenshot/eval 等预览工具，改用系统独立服务进程后台加自动化脚本获取真实渲染数据与盒模型截图。
- **R-17 禁 AI 自测与自拟提示词互喂**：禁测 skill、禁 AI 生成提示词再喂 AI 看效果、禁开子代理做对照实验，只做主人点名的线，意识到在做测试立即终止并如实回报。
- **R-18 共享知识仓私有远程、每次提交即推送**：共享知识/规则/脚本/核心资产仓须建私有远程，缺 remote 视为未完成，每次提交即推 origin 不推 upstream，对外发布前先脱敏。
- **R-19 子代理蜂群**：任务书自包含，一文件一写者且只读角色禁写，主代理非阻塞同轮次并发派发禁串行/wait/轮询，禁消息板中转，重大改动必派红队 nitpicker，三级派发内置→仓内专用→主代理兜底。
- **R-20 mini-trellis 记忆层规范**：知识存 .trellis（spec/research/workspace），只记已确认决策，更新顺序读→编辑→读回→add_session→查 journal，recall 够用即停，每 journal ≤2000 行。
- **R-21 代码复用与跨层思维**：写码前先搜，同一未类型化字段 2+ 处读取建共享 guard，3+ 次才抽象，改值前 grep 全仓，AI 交叉审查约 35% 误报率须回查，多数 bug 在层边界先画数据流。
- **R-22 规则单一真源、索引、短注入、生成物禁手改**：规范全文只住唯一真源，索引只存 ID/级别/摘要/落点，注入块只放短摘要与入口，渲染生成物禁手改，跨仓副本哈希校验漂移即重同步。
- **R-23 事实先于结论、完成需可复现证据、禁报喜不报忧**：声明完成前实跑校验并记录真实数字，证据分层不得相互冒充，数值禁假 0 与假前缀，如实披露失败项，「没查到」写明查过范围与搜索式。
- **R-24 测试全绿零回归、有界等待、失败不静默**：交付前测试全绿零回归，异步必须有界（settle 判据/Worker 置空/rAF 合帧），失败不静默且进度可见，禁空断言占位，关键路径做变异验证。

## 三、正文三：tavern generic 独立条目 T-01~T-07

- **T-01 删除走回收站归档 + Git 显式 pathspec + 暂存区校验**：删除一律走回收站或归档，禁命令直接删；Git 只用显式 pathspec，提交前校验暂存区，完成即推 origin。
- **T-02 脚本禁硬编码业务数据**：脚本禁硬编码业务数据，路径、端口、URL、阈值一律读配置。
- **T-03 脚本中控与仓内脚本目录**：一仓一份脚本目录，模块登记，中控统一派发，禁一次性脚本。
- **T-04 工作流改动覆盖五面并留证据**：工作流改动覆盖 skills、MCP、agent、配置文件与 TDD，并留验证证据。
- **T-05 交互输出物理分行**：多事项物理分行，禁连词、分隔符、括号合并，单项断言独立成行。
- **T-06 对话正文不贴完整文件**：对话正文不贴完整文件内容，落地文件，只给可点击路径。
- **T-07 禁破坏性 git 回滚未提交改动**：禁 checkout --/restore/reset --hard/clean -fd 回滚未提交改动，回滚前先 stash 或备份并报备路径。
