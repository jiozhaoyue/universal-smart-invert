# UI 全面改版：面板布局、规则文件上下传、元素规则与设置重排

## Goal

对设置面板做一次信息架构与视觉的全面改版（v3.3）：面板布局可停靠不必遮罩全屏、任何窗宽下无横向滚动与出界、设置项重排合并并全中文化（下拉选项不带括号、界面不出现代码与英文字段）、规则支持文件导出导入、在站点黑白名单之外新增元素级规则。

## Background（现状问题，均已实地确认）

- 设置页是居中遮罩弹窗（`.svi-modal-mask` + 480px 窗口），没有其他布局形态。
- 行布局为「140px 标签 + 控件同一行」，`.svi-modal-controls` 缺少 `min-width: 0`，`select` 的固有宽度等于最长选项文本 —— 「智能图片策略」选项「平衡 (默认: 正文与大图反色, 封面网格跳过)」把下拉撑出窗口右缘（截图证据），窄窗时引发横向滚动。
- 大量下拉选项把说明写进括号（智能图片策略、图片特效模式、视频特效引擎）；按钮/折叠标题也带括号副标。
- 界面出现代码与英文：`CSS 滤镜`、`(GPU)`、`content:url 投递`、`#FFFFFF` 十六进制预览、存储后端 `chrome.storage.sync`、存储键 `svi:xxx` 原文、统计隐私说明里的 `STATS_KEY / svi:stats`。
- 描述性文案过长且与控件挤在一行；区块顺序按版本迭代堆叠（v2.0 → v3.2），不按使用频率组织；「高级参数微调」折叠抽屉隐藏了 13 个滑杆。
- 规则能力分散：站点模式（黑/白名单）、本站覆盖、学习规则、种子规则、原色屏蔽各自独立呈现；只有整仓存储 JSON 导出，没有面向规则的友好文件；没有元素级规则。
- `SCRIPT_VERSION` 常量仍是 3.1.0（v3.2 漏改）。

## Requirements

### R1 面板布局（不强制 overlay / 全屏）
- 设置页支持三种布局并记忆用户选择：`居中窗口`（现状形态）、`靠左停靠`、`靠右停靠`。
- 停靠形态为全高侧边抽屉：**无全屏遮罩**、不遮挡其余页面（点击面板外部即关闭、Esc 可关闭），宽度可拖拽调节（320–600px）并记忆。
- 居中形态保留遮罩；宽度提升至 600px 并随视口自适应。

### R2 布局健壮性（任何窗宽无横向滚动、无出界）
- 设置主体任何情况下不出现横向滚动条；控件在窄容器内收缩换行，不得溢出窗口边界。
- 行布局改为纵向堆叠：标题与说明在上、控件在下，说明自动换行，不再出现「一行超长描述」。

### R3 下拉与文案净化
- 所有下拉选项只保留简短中文名，**不含任何括号描述**；随选项变化的解释放在下拉下方的动态说明行。
- 全界面去除代码与英文字段：滤镜路径、投递机制、十六进制色值、存储后端与存储键、统计说明等全部改为中文表述（色值仅保留色块，原文进悬浮提示；快捷键名 Alt 除外）。
- 说明文案精简为一句话以内；控件保留全部既有能力（设置尽可能详细，不因改版丢功能）。

### R4 设置信息架构重排（合并同类、按使用频率排序）
- 新顺序（自上而下）：🎨 外观与画面 → 🖼️ 图片反色 → 🎬 视频 → 🌐 站点与规则 → 🛡️ 颜色保护 → 🖥️ 当前页媒体 → 💾 数据与备份 → 💡 操作技巧。
- 合并：折叠抽屉「高级参数微调」解散，13 个滑杆并入对应区块（画面滤镜/过渡→外观与画面；图片阈值→图片反色；视频智能算法→视频）。
- 合并：「数据与反馈」+「存储」→「数据与备份」，按钮按「规则文件 / 全量备份 / 本地统计」分组。
- 「图片特效模式」及亮度/键色参数并入「图片反色」。
- 组件解耦复用：文件保存/选择助手、下拉动态说明、列表编辑等抽为可复用助手，避免区块间复制粘贴。

### R5 规则文件上下传（文件友好）
- 新增「导出规则文件」：下载 `svi-rules-日期.json`，内容覆盖站点模式与名单、本站覆盖、元素规则、学习规则、原色屏蔽、背景排除选择器。
- 新增「导入规则文件」两个入口：合并导入（数组去重合并、覆盖项按键合并、学习规则按命中数取优）与替换导入（整组覆盖），导入前均有确认提示。
- 与既有「全量备份」（整仓存储 JSON）并存，职责在 UI 上说明清楚。

### R6 元素级规则（不止站点黑白名单）
- 新增用户自定义元素规则：`站点范围（本站或全部站点）+ 元素选择器 + 动作（强制反色 / 保持原色）`，列表可删除。
- 决策优先级：手动覆盖 > **元素规则** > 决策快照 > 学习规则 > 种子规则 > 小元素门 > 策略门 > 像素分析；元素规则变更必须强制刷新决策快照并重扫（维持 decide-once 语义）。
- 图片决策管线与背景图引擎均尊重元素规则；规则总数有上限（FIFO 200 条）。
- 「站点与规则」区块整合呈现：本站开关、站点模式与名单、元素规则、学习规则、内置规则摘要——不再只是黑白名单。

### R7 工程收尾
- `@version` → 3.3.0，`SCRIPT_VERSION` 同步修正，`@description` 更新；README.md / README_EN.md 同步。
- 重建扩展产物：`node scripts/build-extension.js && node scripts/pack.js`。
- 单元测试补充元素规则解析与优先级；浏览器基准更新被移除的折叠抽屉断言，并新增元素规则端到端用例。

## Non-Goals

- 不改变任何反色/特效算法本身；不改存储后端机制与手动覆盖数据格式。
- 不做规则文件的云上传（仍为本地文件，符合「绝不自动上传」红线）。
- 不新增外部字体/网络资源（注入任意站点，必须零外链）。

## Acceptance Criteria

- [ ] 设置页可切换居中/靠左/靠右三种布局，选择与抽屉宽度重启后仍记忆；停靠形态无全屏遮罩，点击外部与 Esc 均可关闭。
- [ ] 在 1280×800 与 500×600 两种视口下打开设置页：无横向滚动条；截图中最长下拉（智能图片策略等）不再出界。
- [ ] 全部下拉选项不含括号；选项变更时下方动态说明行更新。
- [ ] 界面（含选项、徽章、按钮、键列表、统计说明）无 `CSS`、`GPU`、`content:url`、十六进制串、`svi:` 键名、`chrome.storage` 等代码/英文表述（色值悬浮提示与 Alt 快捷键名除外）。
- [ ] 设置区块按 R4 顺序排列；原折叠抽屉内滑杆全部可见于对应区块；「数据与备份」内规则文件/全量备份/本地统计三组按钮齐全。
- [ ] 导出规则文件可在另一页面导入：合并导入不丢已有规则且去重；替换导入完全覆盖；导入后生效。
- [ ] 添加元素规则（本站 + 选择器 + 强制反色/保护）后，匹配图片立即按规则决策，且优先于学习规则与像素分析；删除规则后恢复自动决策。
- [ ] `node --check`、`node test.js`、`node test-browser.js`、`node scripts/build-extension.js && node scripts/pack.js` 全绿。
