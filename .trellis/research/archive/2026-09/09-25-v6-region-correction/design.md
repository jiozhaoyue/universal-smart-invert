# Design: v6-3 纠正与自校准数据回路

> 上游：v6-1 掩码契约（冻结）、v6-2 渲染层（已落地）。
> 本任务的定位**不是**给部分反色加人工绘制入口（D1 已排除），而是给分割器**补监督信号**：
> 在自动结果之上做一次「点击级二值纠正」，产出分割器唯一缺的**掩码差分样本**。

## 1. 边界

**做**：纠正模式（可视化 + 一次点击翻转）→ 掩码差分样本 → 持久化（站点 + 选择器 stem）→
保守自校准（幅度上限、累积门、一键回滚、可观测）。

**不做**：
- **不做任何绘制型交互**（无套索 / 无笔刷 / 无顶点拖动 / 无多边形构造）。唯一手势是**点击**。
- 不改掩码契约（差分是两份 `RegionMask` 之差，契约只读）。
- 不改整图判定的既有阈值（那是 v5-3 的回路），**只动分割参数**。
- 不新建第二套持久化机制（复用 `Store` + `ruleStem` + 规则包通道 + `manualOverrides` 键风格）。
- 不施压：不提示 / 不徽标 / 不计数催用户纠正。

## 2. 现状接缝

| 事实 | 位置 |
| :-- | :--- |
| 分割参数单一真源 | `REGION_DEFAULTS`（v6-1）+ `state.regionGridN/MinAreaRatio/KRects` |
| 渲染层挂载/卸载/重算 | `RegionRenderEngine`（v6-2，section 20.5） |
| 掩码三层直连 | `regionByElement` / `regionBySrc` / `regionCache` |
| 元素盒网格（元素盒坐标） | `regionRenderExpr` → `box.grid` |
| 站点键 / 元素词干 | `profileKey()` / `selectorStem(el)` |
| 持久化 + 规则包往返 | `Store.get/set('svi:*')`、`export-rule-library.js` / `rules/svi-pack*.json` |
| 手动结论键风格 | `manualOverrideKey(profileKey(), src)` |

## 3. 架构决策

### D1 — 纠正的载体：**元素盒网格上的翻转集**，而不是"画出来的形状"

一次点击的语义：
```
点击点 → 元素盒坐标 → 元素盒网格格号 → 该格所属的**连通域** → 整个连通域判定取反
```
- 连通域按 v6-1 的 `regionComponents`（8 邻域）在**纠正后的网格**上重新计算 ✓ 复用既有实现。
- 产出物是**一份完整的纠正后网格**（`Uint8Array`，与 `box.grid` 同尺寸），
  于是「翻转后的渲染」= 用纠正后的网格重挂覆盖层 —— 与 v6-2 的渲染路径完全同构，**零特殊分支**。
- 为什么是"整个连通域"而不是单格：单格翻转会产出椒盐掩码；区域的语义单位就是连通域。

### D2 — 差分的定义

```
diff = XOR(我们算出的网格, 用户纠正后的网格)
```
- `diffCells = 0` → 本次点击是"翻回原位"（等价于没纠正）→ **不产出样本**（不污染数据）。
- 样本形状：`{ host, stem, dims: 'WxH', n, ours: 位串, corrected: 位串, diff: 位串, at }`。
- 位串用 `'0'/'1'` 字符串（≤1024 字符，可读、可 diff、JSON 友好；不用 base64 —— 可读性优先）。

### D3 — 持久化：复用既有通道

- 新增 `Store` 键 `svi:regionCorrections`：`{ v: 1, samples: [...], calibration: {...} }`。
- 键里带 `host` + `stem`（R4）：命中 → 加载时对该元素应用纠正后的网格；未命中 →
  **仅本次会话生效**（如实标注的已知局限，不引入内容指纹）。
- 规则包往返复用 `rules/*.json` 的既有导出/导入通道（本任务只把 `regionCorrections`
  加进导出的白名单，不写第二套导入导出代码）。
- 上限：样本 ≤ 200（FIFO 淘汰）、单样本 ≤ 2KB。

### D4 — 自校准：保守、可回滚、可观测

**只动一个参数**：`regionMinAreaRatio`（最小连通域面积门）。
理由：它是「抠多大才算一个区域」的唯一旋钮，纠正数据能直接告诉它方向；其余参数
（网格 N、K、核大小）需要更细的信号，本片不碰（避免"用粗糙信号动敏感参数"）。

判据（纯函数，输入 = 样本集，输出 = 建议）：

| 观测 | 含义 | 动作 |
| :-- | :-- | :--- |
| 用户把**我们抠掉的**区域翻回「反色」（`diff` 里 0→1 为主） | 我们**抠多了**（小东西被当成特征块） | `minAreaRatio` ↑（更保守） |
| 用户把**我们反色的**区域翻成「保持原色」（1→0 为主） | 我们**抠少了**（该保护的没保护） | `minAreaRatio` ↓（更激进） |
| 两类持平 | 无明确方向 | **不动** |

护栏（全部参数化 + 单测）：
- **累积门**：样本数 ≥ `regionCalibrateMinSamples`（默认 5）才评估；
- **幅度上限**：单次调整 ≤ `regionCalibrateStep`（默认 0.005）；
- **钳制**：结果落在 `[0.01, 0.25]`；
- **方向一致性**：只有多数样本同向（占比 ≥ 2/3）才调，否则视为噪声不动；
- **一键回滚**：`state.regionMinAreaRatio = REGION_DEFAULTS.minAreaRatio`（单一真源）；
- **可观测**：记录 `{ at, from, to, samples, direction }`，面板显示「因 N 个样本从 X 调到 Y」。

### D5 — 与 v6-2 渲染层的关系

纠正模式进入时：
1. 对已挂载的区域层，叠加一层**可视化**（半透明着色 + 区域轮廓 + 图例：反色 / 保持原色）；
2. 点在可视化层上 → 命中元素盒网格的连通域 → 翻转 → 重挂该元素的覆盖层；
3. 退出模式 → 撤掉可视化层，但**保留纠正后的渲染**（这正是 PRD R1 的语义）。

可视化层与覆盖层同级（同一个定位祖先），`pointer-events: auto`（唯一允许接收点击的层），
且**只在纠正模式下存在**。

### D6 — 零遥测

所有数据只走 `Store`（本地）。规则包导出是**手动**动作，不新增任何网络调用。
核查方式：bench/单测里对 `fetch` / `GM_xmlhttpRequest` 的调用点做 diff（与 v5.0.0 逐条一致）。

## 4. 风险

| 风险 | 处置 |
| :-- | :--- |
| 走偏成"绘制工具" | 全部交互只有 `click`；单测/grep 核查不存在 `mousedown`+`mousemove` 构造几何的路径 |
| 纠正数据污染全局参数 | 自校准只动 `regionMinAreaRatio`，有累积门/幅度上限/方向一致性/一键回滚 |
| 样本无界增长 | 样本 ≤200、单样本 ≤2KB、FIFO |
| 与手动覆盖（Alt+点击）混淆 | 语义不同：Alt+点击 = 整图结论；区域纠正 = 区域级判定。两者并存，区域纠正不写 `manualOverrides` |
