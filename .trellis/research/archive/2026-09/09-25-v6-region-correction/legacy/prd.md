# PRD: v6-3 纠正与自校准数据回路

## 背景与定位（先澄清一个常见误解）

D1 已裁决：部分反色是**全自动**，**不存在用户手动划选入口**。本任务**不是**给部分反色
加一个人工绘制入口——那是被明确排除的。

本任务要解决的是另一个问题：**自动分割器的参数是拍的**。网格粒度、明度线、饱和度线、
形态学核大小、最小连通域面积门——这一串默认值目前没有任何**监督信号**可以校准。

v5-3 的 `data-loop` 已有「阈值自校准」，但它吃的是**站点级命中率**这种粗糙信号：只知道
「这个站我们判错得多」，不知道「具体错在哪一块」。本任务补的正是缺失的那一环：
**在自动结果之上做一次点击级二值纠正，产出分割器唯一缺的掩码差分样本。**

### 与「手动划选」的区别（必须守住）

| | 手动划选（D1 排除） | 本任务的纠正（允许） |
| :--- | :--- | :--- |
| 交互成本 | 画多边形 / 套索 / 笔刷 | **点一下** |
| 输入内容 | 用户在构造区域 | 用户在**评判**自动产出的区域 |
| 是否必需 | — | **完全不必要**，不纠正就跑默认参数 |
| 定位 | 功能入口 | **数据采集通道** |

## Requirements

### R1 — 纠正交互（二值翻转，不是绘制）
- 显式的「区域纠正模式」（**默认关闭**，需用户主动进入）：
  - 进入后，把该媒体上自动分割出的区域**可视化**出来（区域边界 + 当前判定：
    反色 / 保持原色）；
  - **点击一个区域 = 翻转它的判定**。仅此一种操作，不提供绘制、拖动顶点、自由形状。
  - 退出该模式后，被翻转过的区域按纠正结果渲染。
- 交互成本必须是「一次点击」量级；**不得**引入任何需要构造几何形状的手势。
- **AC**: bench 断言点击翻转后该区域判定改变且渲染跟随；`grep` 核查不存在绘制类手势
  （`mousedown`+`mousemove` 采样路径构造多边形的代码）。

### R2 — 掩码差分产物
- 每次纠正产出一份差分样本：`{ 站点, 选择器 stem, 图片维度指纹, 我们算出的掩码,
  用户纠正后的掩码, 差分区域 }`。
- 差分是**自校准的输入**，不是给用户看的报表（但需可在面板查看与清空）。
- **AC**: 单测差分构造（含无差分、全翻转、部分翻转三种）；面板可列出与清空。

### R3 — 自校准
- 用累积的差分样本调整分割参数。校准必须是**保守且可回滚**的：
  - 单次校准的调整幅度有上限；
  - 累积到阈值才动，不因单次纠正就改全局参数；
  - **可一键回滚到默认参数**；
  - 校准效果可观测（面板显示「本参数因 N 个样本从 X 调到 Y」）。
- 校准**只影响分割参数**，不得影响整图判定的既有阈值（那有 v5-3 自己的回路）。
- **AC**: 单测校准的幅度上限、累积门、回滚；bench 断言校准后同一输入掩码发生变化。

### R4 — 泛化键：站点 + 选择器 stem（D4）
- 纠正数据按 **`站点 + 选择器 stem`** 持久化，复用现有 `ruleStem` 机制与规则包
  导出/导入通道（含 array merge 去重与幂等）。
- **不引入内容指纹**（D4 已排除）。已知局限如实说明：同一站点不同版式的图可能不命中，
  此时回退到「仅本次会话生效」。
- 复用现有 `state.manualOverrides` / `manualOverrideKey(profileKey(), src)` 的键风格，
  **不新建第二套持久化机制**。
- **AC**: 单测 stem 命中 / 未命中 / 规则包往返；导出导入后行为一致。

### R5 — 可选性（不得变成必需品）
- 不进入纠正模式的用户，功能完全可用，只是跑默认参数。
- 不得用任何形式的提示 / 徽标 / 计数施压用户去纠正。
- **AC**: 全默认状态下（零纠正）四绿门禁全绿；面板不出现「建议纠正」类文案。

### R6 — 零遥测
- 纠正数据全本地存储，**不产生任何网络出口**；网络出口与 v5.0.0 逐条一致。
- 进规则包是**手动导出**，不是自动上传。
- **AC**: `diff` 出口行比对为空。

### R7 — 开关与可观测
- 「区域纠正模式」开关、「用纠正数据自校准」开关（**默认关**）、「清空纠正数据」入口。
- 面板只读诊断：累积样本数 / 最近一次校准时间与参数变化 / 回滚按钮。
- **AC**: 各开关单测；关闭自校准后不再改动参数。

## Constraints

- **绝不引入绘制型交互**（D1）。这是本任务最容易走偏的地方。
- 不得新建第二套持久化机制（复用 `ruleStem` + `manualOverrides` + 规则包通道）。
- 不得影响整图判定的既有阈值与 v5-3 的自校准回路。
- 纠正数据属于用户个人数据：不得进仓库、不得进日志、不得上报。
- 注释与文档全中文。

## Acceptance Criteria（汇总）

- [ ] 区域纠正模式：可视化区域 + 一次点击翻转，零绘制手势
- [ ] 掩码差分产物可构造、可查看、可清空
- [ ] 自校准保守可回滚，幅度上限与累积门有单测
- [ ] 泛化键为站点 + 选择器 stem，规则包往返幂等
- [ ] 零纠正时功能完整可用，面板无施压文案
- [ ] 零遥测：网络出口与 v5.0.0 逐条一致
- [ ] 全部开关默认关；全关时与 v5.0.0 一致
- [ ] 四绿门禁全绿

## Notes

- 依赖 v6-1 的**掩码契约**（R2 的差分就是两份 `RegionMask` 之差）与 v6-2 的渲染层
  （R1 的点选要作用在渲染出的区域上）。
- 本片是批1 ③，必须在 ② 定型后开工。
- 校准**不是**必须的：它的价值是「用户纠正过 → 以后更准」，不是「必须纠正才能用」。
