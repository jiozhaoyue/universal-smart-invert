# Universal Smart Video Invert (全网通用智能视频反色与全媒体演进)

## Goal (目标)

构建一款全网通用（`@match *://*/*`）的 HTML5 智能视频反色油猴脚本。精准锁定当前播放的主视频及小窗，杜绝污染控制栏、弹幕、字幕与页面其他元素；基于低开销离屏采样实现智能感知白底 PPT 课件并自适应反色，独创“无对抗人机协同状态机”确保用户随时人工纠偏且不反复打架；采用极简边缘悬浮胶囊与全局快捷键（`Alt+I` / `Alt+A`）；预留通用媒体引擎架构，第二阶段无缝接入图片等可视媒体。

---

## Confirmed Facts & Technical Insights (已确认事实与技术共识)

1. **作用域与精准性**：
   - 必须精准作用于 `HTMLVideoElement`（`<video>`）本身，坚决不对 `html` / `body` 施加破坏性全局滤镜。
   - 播放器控制栏、弹幕（Canvas/DOM）、外挂字幕天然处于更高层级 DOM，直接作用于 `video` 即可保证它们 100% 不受反色污染。
   - 准确跟踪主视频及小窗形态切换（PiP / 页面右下角悬浮迷你播放器），自动忽略尺寸小于 $240 \times 160$ 的微型预览广告或悬浮列表卡片。

2. **反色色彩配方**：
   - 核心滤镜公式：`filter: invert(1) hue-rotate(180deg)`。
   - 提供实用两档预设：
     - **柔和灰反色（默认）**：`invert(1) hue-rotate(180deg) brightness(0.92) contrast(0.90)`，模拟纸张印刷质感，不刺眼。
     - **纯黑高对比反色**：`invert(1) hue-rotate(180deg) brightness(0.75) contrast(1.10)`，适合强光环境或暗室 AMOLED。

3. **智能白底课件识别算法**：
   - 后台极轻量离屏微型 Canvas（$32 \times 32$，仅 1024 个采样点），每 1 秒抽检一次原视频帧。
   - **判定依据**：
     - 计算高亮像素占比 $R_{white}$（感知亮度 $L = 0.299R + 0.587G + 0.114B > 215$ 的像素占比）；
     - 计算平均色度饱和度 $S_{avg}$；
     - 触发条件：$R_{white} \ge 65\% \land S_{avg} \le 20\%$。
   - **优先课件护眼**：以大面积白底课件护眼为主，即使角落有教师真人小窗也优先保证课件反色变暗。

4. **无对抗人机协同状态机 (Non-Conflicting HIL State Machine)**：
   - 离屏 Canvas `drawImage(video)` 提取的是视频流的**原生未滤波像素**，不受当前 CSS 滤镜影响。
   - 当自动逻辑误反色时，用户通过 `Alt+I` 或点击胶囊调回原色后，脚本记录当前画面的“被否决场景指纹”。
   - **只要视频画面维持在该场景特征内，自动检测器绝不擅自反弹**；仅当视频画面真正发生场景级变化（如切回正常真人镜头或跳入全新白底章节）时，才重新接管评估。

5. **CORS 跨域安全韧性**：
   - 采样操作全部置于 `try-catch` 保护内。若遇跨域严格限制导致 `Tainted canvas`，自动平滑退化为手动/快捷键模式，并在胶囊状态上标注 `Manual (CORS)`，坚决不报错崩溃。

## Requirements (核心需求)

### 1. 作用域与多平台支持 (Scope & Targeting)
- **REQ-1.1**：全网匹配（`@match *://*/*`），自动适配 Bilibili、YouTube、腾讯视频、爱奇艺、优酷及各类 HTML5 视频站点。
- **REQ-1.2**：主视频精准探针：根据尺寸权重、播放状态、可见性识别主视频，支持小窗/画中画连续跟踪，自动排除无关悬浮预览。
- **REQ-1.3**：零区域污染：弹幕、字幕、播放器控制条、网页文字与图片完全保持原生状态。

### 2. 智能反色与非对抗状态机 (Smart Invert & HIL State Machine)
- **REQ-2.1**：轻量微型离屏采样（$32\times32$，1次/秒），毫秒级计算白底占比与低饱和度特征。
- **REQ-2.2**：防闪烁迟滞缓冲（Hysteresis）：进入阈值（白底 $>65\%$）与退出阈值（白底 $<45\%$ 且持续 1.5s），配合 `transition: filter 0.3s ease` 平滑过渡。
- **REQ-2.3**：非对抗人工覆盖：用户手动调色/恢复时，当前场景特征被记忆为抑制态，直到下一次真实场景巨变前不发生人机对抗。
- **REQ-2.4**：CORS 优雅降级：跨域受限视频静默降级为手动快捷键操作，绝不抛出未捕获异常。

### 3. 交互与控制体系 (UI & Controls)
- **REQ-3.1**：极简边缘悬浮胶囊：平时呈微型半透明小点吸附在屏幕边缘，支持拖拽；点击展开小面板（状态显示、模式切换、预设选择）。
- **REQ-3.2**：全屏自隐：视频全屏播放时自动隐藏悬浮胶囊，避免遮挡沉浸观影。
- **REQ-3.3**：全局快捷键支持：
  - `Alt + I`：快速切换反色 / 还原（带有人工覆盖保护）；
  - `Alt + A`：快速开启 / 关闭自动智能感知模式。
- **REQ-3.4**：极简双档预设（柔和灰 / 纯黑）及自定义微调通道。

### 4. 架构演进与扩展性 (Architecture Evolution)
- **REQ-4.1**：抽象 `MediaInvertEngine` 核心处理管线，将视频的“探测器”、“滤镜应用器”、“状态机”解耦，便于 Phase 2 直接挂载 `ImageInvertEngine` 扩展至文章插图与全媒体。

## Out of Scope (本期暂不纳入)

- 图片等静态可视媒体的自动反色（已明确列为 Phase 2，本期重点打牢多平台视频与算法核心）。
- 绕过 DRM 加密流（如 Netflix L1 硬件保护流）。

## Acceptance Criteria (验收标准)

- [x] 在 Bilibili、YouTube 等多站点上，仅 `<video>` 画面生效反色，弹幕、字幕、进度条、菜单完全无负片现象。
- [x] 播放白底 PPT 课件视频时，可在 1.5 秒内自动平滑过渡为柔和暗底；切入真人实拍镜头时平滑恢复。
- [x] 自动误触发后，按下 `Alt+I` 即可纠正为原色，后续播放同类画面时不会被脚本反复改回（无人机对抗）。
- [x] 悬浮胶囊在边缘半透明吸附，点击展开迅速，全屏时自动隐藏。
- [x] 即使在跨域限制视频上，脚本不崩溃、不卡顿，快捷键依然能正常手动反色。
