# PRD: v6-1 自动区域分割内核（掩码契约冻结）

## 背景

现有图片反色判定是**整图一次**：8×8 降采样 → 统计「高感知明度占比」与「平均饱和度」
两个特征 → 输出一个布尔结论。只有「全反」与「全不反」两个挡位。

对「一张图里既有浅底又有不该动的内容」的图，两边都不对：

- 白底 PPT 截图里嵌了一张彩色照片 / 二维码 / 品牌 logo → 整图反色把照片变成负片；
- 深色代码截图里有一块白色高亮 → 整图不反色，那块白继续刺眼。

现有 `luma`（亮度反色）模式已经在做这件事的**逐像素近似**（基准图
`/img/fx-halfwhite.svg` 的注释即「左半纯白应被反色，右半高饱和蓝应保留」）。但它作用在
单个像素上：彩色照片会被按亮度部分反色成一块中间态，且保不住完整区域的原色。

本任务把**判定单位从整图下沉到连通区域**。

## 定位澄清（D1，不得偏离）

部分反色是**全自动**的：**不存在用户手动划选入口**。本任务产出的区域来自自动分割，
不是用户绘制。底层几何管线（掩码 → clip-path / mask-image）仍然要做，但它的**输入源是
本任务的输出，不是交互绘制**。

**不引入新算法**：判别信号完全复用现有的两个特征（高感知明度占比 `L > 210`、平均
饱和度 `S_avg ≤ 22%`），只是从「全图统计一次」变成「分块统计 N 次」。零 ML、零语义分割、
零新依赖、零网络。

## Requirements

### R1 — 分区判定管线
- 降采样从 8×8 提升到 **N×N 网格**（N 默认 16，可调，上限 32；小图按比例降级）。
- 逐格独立计算两个特征，得到格子级评分。
- 二值化：每格输出「该反色 / 不该反色」。

### R2 — 形态学尾治理
- **闭运算**（先膨胀后腐蚀）填掉误判的小洞。
- **开运算**（先腐蚀后膨胀）去掉孤立的小块。
- **最小连通域面积门**：只保留面积 ≥ **整图 3%**（D3，保守大块）的连通域；
  面积不足的连通域**一律跟随其邻域多数判定**，不为了一小块白点把按钮挖出来。
- 核大小与面积门参数化，可在面板调整。

### R3 — 默认方向（工程关键，不得搞反）
-** 不是「找该反色的区域」，而是「找不该反色的区域，其余默认为该反」。**
- 理由：白底黑字里字与字之间的白缝会被误判成独立区块，产生碎裂掩码；反过来只有明确的
  彩色/深色区块被挖掉，鲁棒得多。
- 主场景（浅底图挖彩色插图）直接落在这条默认方向上。
- 对偶场景（深底图挖浅色区块去反色）作为**另一条极性**实现，由整图判定结果选择极性。

### R4 — 掩码契约冻结（本任务的**核心交付物**）
- 产出物必须是**唯一的数据契约**，v6-2（渲染层）与 v6-3（纠正回路）消费它，
  两片**不得**各自重新实现分割或各自定义掩码结构。
- 契约至少须承载：网格尺寸、逐格二值数据、覆盖率、极性、**来源**（走分割 / 退化为整图 /
  不反色）、**降级原因**（读不到像素时必须是显式的，不能静默）、以及可选的量化位图。
- 契约冻结后写入 spec，后续子任务只消费不修改。
- **AC**: 契约的单测（构造 → 序列化 → 消费）全绿；`grep` 核查不存在第二处分割实现。

### R5 — 双性能门（保护热路径）
- **第一道（进分割前）**：整图浅色占比 ≥ 90% 或 ≤ 10% → 直接走现有整图路径，
  **零分割开销**。只有落在中间带的混合图才付分割成本。
- **第二道（分割后）**：分割得到的「该反色面积」若又退到 ≥ 90% 或 ≤ 10%，
  退回整图路径，**连掩码层都不挂**。
- **AC**: 两道门各有单测（边界值 0.90 / 0.10 的两侧）；bench 断言纯浅色图与纯深色图
  的分割函数调用次数为 0。

### R6 — 输出表达
- **位图 mask 为主**：量化后的 N×N 位图，供 `mask-image` + `mask-size: 100% 100%` 使用。
  理由：不吃 marching squares 提轮廓的实现量，16×16 双线性放大的边界天然柔和。
- **矢量快路径**：当掩码可简化为 ≤ K 个矩形（K 默认 3）时，改用 `inset()`/`polygon()`
  表达，省掉一次图像解码。K 与阈值参数化。
- 两种表达都必须是 `RegionMask` 契约的一个字段（`expression: 'bitmap' | 'vector'`），
  消费方不需要分支。
- **AC**: 两种表达在同一掩码上的**渲染结果像素级等价**（bench 断言）。

### R7 — 读不到像素必放行
- 跨域 / CORS / 解码失败 → **不分割、不挂 mask**，退化为整图判定；契约里
  `degrade.reason` 必须显式标明。
- 绝不「拿不到像素就乱挂 mask」，绝不「拿不到像素就把内容藏起来」——与 v5-5
  「判定失败必放行」同一纪律。
- 复用现有 canvas 污染隔离链，不得新增第二条解码路径。
- **AC**: 模拟跨域失败页，bench 断言零 mask 层挂载、`degrade.reason` 非空。

### R8 — 缓存与内存
- 掩码按图缓存（键与淘汰策略需在设计阶段定死）。长页面不得堆积。
- 缓存命中时零重复计算。
- **AC**: 单测缓存命中/淘汰；bench 断言同图重复出现不产生第二次分割。

### R9 — 开关与可观测
- 「自动区域分割」总开关 + 网格粒度 N + 明度线 + 饱和度线 + 形态学核大小 +
  最小面积门 + 矢量快路径 K 值，全部可调；**默认关闭**。
- 面板只读诊断行：本会话分割次数 / 平均耗时 / 降级次数（分原因）/ 缓存命中率。
- **AC**: 各开关单测；关闭后不产生任何分割调用。

## Constraints

- **纯统计，零 ML、零语义分割、零新依赖、零网络**。
- 不得改变现有整图判定路径的行为；全关时与 v5.0.0 逐字节一致。
- 新增判定**不得进入热路径**（帧内同步路径不得引入新的 `getComputedStyle` / 布局查询）。
- 性能：分割路径单图判定耗时须仍在 **<1ms** 量级（设计阶段给出实测预算）。
- 注释与文档全中文。
