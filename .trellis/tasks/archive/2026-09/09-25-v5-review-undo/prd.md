# PRD: v5-2 复查撤销 — 撤销栈 + 本页已处理列表 + 一键固化

## 背景（含现状核查结论）

v3.1 R3 已实现「🖥️ 当前页媒体」面板：采集当前页媒体（预算 400）、逐项「反色/复原」按钮、
「定位」按钮（`scrollIntoView` + 1.2s 描边闪烁）、索引化 `data-svi-mi` 避免持有 DOM 引用、
惰性采集（点按钮才全页扫描）。

**缺的正是用户说的那一层**：面板列的是「页面上有什么」，不是「脚本刚刚改了什么」。
用户看到一张图被反错了，仍要在页面上把那张图找出来。

现状能力盘点：

| 能力 | 现状 |
| :--- | :--- |
| 撤销最近一次 | **无** |
| 决策历史 | **无**（`decisionBySrc` 只有当前结论，无时间序） |
| 原因码可见 | 仅跳过原因（`SKIP_REASON_ZH`），**反色侧原因码不可见** |
| 定位到元素 | 有（`locateMedia`） |
| 一键固化规则 | **无**（列表项只能逐次手动切） |
| 复检改判提示 | 复检网在跑（`queueRecheck`），**结果不可见** |

## Requirements

### R1 — 撤销栈
- 环形栈 `undoStack`，容量 30，每项 `{ id, action, stem, src, reason, source, at, params }`。
- **只记自动结论**（`source ∈ {'pixel','learned','profile','seed'}`），不记手动动作
  （手动是用户意志，不提供「撤销用户自己」的语义）。
- `Alt+Z` = 撤销最近一次（逐个回退，重复按继续向前）。栈空时 toast 提示。
- **AC**: 单测入栈/出栈/容量回卷；bench 断言 `Alt+Z` 后元素回到原状态。

### R2 — 可交互 toast
- `showToast` 现有实现 `pointer-events:none`，新增 `showActionToast(msg, actions)` 变体：
  右侧一个「撤销」按钮，4s 超时（可配置），点击即触发 R1 的撤销。
- **只在 `reason === 'pixel'`（自动像素判定）时弹**。规则/学习/时间线的结论不弹。
- 反色批量发生（同一 flush 内 ≥3 张）时合并为一条 toast（「已反色 5 张 · 撤销」）。
- **AC**: `showActionToast` 单测；bench 断言按钮可点且点击后状态回退；批量合并计数正确。

### R3 — 「本页已处理」列表（升级现有「当前页媒体」）
- 现有媒体段升级为**双视图**：
  - **已处理视图（默认）**：只列本次会话**被脚本改过**的元素（invert / keep-by-rule /
    hide / mask / dim），按时间倒序，显示：缩略图、元素路径（`selectorStem`）、
    **原因码中文**（`pixel` / `已学规则(命中N)` / `站点规则` / `种子规则` / `遮罩否决` /
    `透明底`）、发生时刻。
  - **全部媒体视图**：现有 v3.1 行为（原样保留，不回归）。
- 每项操作：切换（反色 ⇄ 复原）、定位（复用 `locateMedia`）、**固化规则**（R4）、移除。
- 一键「全部还原」（仅作用于已处理视图，带二次确认 toast）。
- 复检网（`queueRecheck`）改判时，对应项打「已复检改判」标记并置顶 5s。
- **AC**: bench 断言已处理视图条目数 == 实际被改元素数；定位滚动与描边生效；
  复检改判标记出现。

### R4 — 一键固化规则
- 列表项 / 撤销 toast 旁的「以后都这样」：
  - 「此元素永不反色」→ 学习层 `action:'keep'`
  - 「此元素永久屏蔽」→ 学习层 `action:'hide'`（依赖 v5-1）
  - 「此站不再自动反色图片」→ 站点偏好 `imageInvert=false`
- 固化后写入学习层，hits 起始为 `learnHits`（默认 2）使之立即生效，并在 toast 里说明
  「已生效（无需再点 2 次）」。
- **AC**: 单测固化后规则立即出现在 `RuleLearner.rulesFor(host)`；bench 断言固化后新加载
  的同 stem 元素直接按规则处理。

### R5 — 错误反色哨兵
- 记录 `src`/`stem` 维度的「被自动反色 → 被用户还原」事件。同一 `src` 24h 内被还原 ≥2 次
  → 自动降级为 `keep` 并入队本页复查提示（toast：「这张图已按你的历史修正改为不反色」）。
- 同一 `stem` 24h 内被还原 ≥3 次 → 建议固化（面板提示，不自动写规则）。
- 与 v5-3 的 `falseInvert` 计数共用同一份记录（契约在 v5-3 定义，本片先落地记录点）。
- **AC**: 单测阈值边界（第 1 次不降级、第 2 次降级）；bench 断言降级后重扫保持原样。

### R6 — 开关
- `undoEnabled`（默认**开**）、`undoStackSize`（默认 30）、`actionToast`（默认开）、
  `errorSentinel`（默认开）。全部可在「🧩 元素动作」区块调。

## Constraints

- 撤销栈**仅内存**（标签页隔离，不写入存储 —— 与 `runtime` 同纪律）。
- 不得让「已处理视图」在打开面板时触发全页扫描（保持 v3.1 的惰性设计）。
- 不得持有 DOM 强引用（沿用现有索引化 `data-svi-mi` 方案，防内存泄漏）。

## Acceptance Criteria（汇总）

- [ ] 撤销栈 + `Alt+Z` + 可交互 toast 全部落地，单测覆盖
- [ ] 「本页已处理」视图条目数与实际被改元素一致，含原因码与来源
- [ ] 一键固化三类规则均可生效，且立即（不需累计 hits）
- [ ] 错误反色哨兵按阈值自动降级，与 v5-3 计数共用记录点
- [ ] v3.1「全部媒体」视图行为不回归
- [ ] 四绿门禁全绿
- [ ] 文档：README / README_EN 补复查与撤销使用说明（含 `Alt+Z`）

## Notes

- 依赖 v5-1 的 `resolveAction`（来源标注）与 `hide` 动作。
- 本片的「固化」是 v5-3「采集 → 消费」回路的第一条真实入口。
