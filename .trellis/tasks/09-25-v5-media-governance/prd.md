# PRD: v5 页面媒体治理层（父任务）

## 来源需求（用户 2026-09-25 原话，逐条落位）

> 继续 trellis 任务，继续优化，也讨论高难度：
> 1. 提前读取视频、动图，能更精准的反色，这种该怎么做？
> 2. 以及存在复查功能，防止错误反色后只能手动点
> 3. 还有数据采集，到底怎么能真的利用上
> 4. 还有强硬保护措施：在加载前将相关元素遮罩，加载完后取消
> 5. 以及看现有的功能，比如上面的功能，可以扩展为屏蔽某些元素等，增加遮罩，可移动鼠标解除，
>    再看看还有什么功能可以扩展，可以扩展为非本插件想要做的功能，但是做都做了，不如扩展下的那种
> 6. 这些全部可以开关配置

## 定位

把插件从「反色器」扩展为**通用页面媒体治理层**：一套元素动作表（invert / keep / hide / mask /
dim / peek），一套消费回路（采集 → 权重 → 决策），一套保护与复查机制。反色仍是主路径，
新增动作是同一管线的边际扩展，不是新架构。

## 已裁决事项（用户 2026-09-25 拍板，子任务不得擅自改）

| 编号 | 决策 | 结论 |

| D1 | 任务组织 | 父任务 + 5 子任务，分两批。批1 = 动作统一 / 复查撤销 / 数据闭环；批2 = 提前判定 / 加载前遮罩 |

## 跨子任务验收标准（父任务级）

- [ ] AC-1 **统一抽象落地**：invert / keep / hide / mask / dim / peek 六种动作全部经单一
      `resolveStage(el, ctx, stage)` + 有序来源表解析，真实优先级链
      `手动 > 用户元素规则 > 【决策快照】 > 学习规则 > 种子保护 > favicon跳过 > 种子强制反色`
      有单测覆盖（注意快照卡在链中间，位置不得移动）；不存在第二处独立的优先级判定实现
      （代码级核查，`grep` 可证）。
- [ ] AC-2 **全量可开关**：六个动作各有独立开关，且每个开关都声明**作用域**（全局/本站）与
      **生效时机**（立即 / 下次加载），面板可见。全部关闭后行为**逐字节等价于 v4.6.1**
      （回归基线：`node test.js` + `node test-browser.js` 24 场景全绿且无新增属性写入）。
- [ ] AC-3 **默认零回归**：新增动作默认**全部关闭**，反色主路径的决策结果、属性写入点
      （`applyInvertState` 收口）、白底判定阈值均不变。四绿门禁全绿。
- [ ] AC-4 **采集有消费**：`learned` 数据至少有一条路径真实改变决策（hits 分级权重），
      面板可出示「本条结论来自学习规则（命中 N 次）」。
- [ ] AC-5 **错误可逆**：任何自动反色结论在 30 步内可撤销；本页已处理媒体可在列表内逐项还原，
      无需在页面上寻找元素。
- [ ] AC-6 **遮罩不伤人**：遮罩预算（总时长 / 元素数）在任何场景下必被兑现，判定失败必放行原图；
      遮罩期内用户可一键全局关闭（`Esc` 或胶囊按钮）。
- [ ] AC-7 **零遥测不被破坏**：运行时代码不新增任何网络读取（`grep -nE "fetch|XMLHttpRequest|navigator.onLine|connection\."` 出口不变），
      规则包导入仍是唯一手动联网通道。

## 约束

- **单文件真源**：`universal-smart-invert.user.js` 是唯一权威源，`extension/` 为生成物，绝不手改。
- **形态差异必须显式**：用户脚本 `@run-at document-end`，扩展 `document_start`。任何依赖
  「早于首帧」的能力（加载前遮罩）都必须分形态说明，不得让用户以为开关坏了。
- **零外部依赖 / 离线自持**：不得引入 CDN、不得内联 demuxer 之类重依赖（D2 已排除了需要
  demuxer 的方案）。
- **性能预算不放宽**：视频单帧检测仍 <0.01ms 量级；图片单张 <1μs 量级；新增判定不得进入热路径。
- **默认保守**：会改动 DOM 观感的新动作（hide/mask/dim）默认关，且首次启用给出说明。

## 非目标

- 云端聚合 / 自动上报（违反零遥测承诺）。
- MSE 分片钩子、带外预解码（D2 排除）。
- 跨浏览器同步后端（Store 后端链保持现状）。
