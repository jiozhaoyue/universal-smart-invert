一款专为夜间与长久用眼打造的 **全网通用智能 HTML5 视频与技术图表反色** 油猴脚本（Userscript）。

专为解决 **网课/编程/教程视频中刺眼的纯白 PPT 课件**，以及 **技术文档中高亮刺眼的白底架构图、流程图与论文插图** 而生。

## ✨ 核心特性

### 1. 🎯 零污染精准作用域 (Precision Scoping)
- **拒绝粗暴的全局滤镜**：坚决不对 `html` 或 `body` 施加破坏性全局反相；
- **弹幕与字幕原生保护**：滤镜直接以原子方式挂载在活动 `<video>` 与白底 `<img>` 自身；
- **控制栏与交互不受扰**：B 站、YouTube 等平台的**播放器控制条、进度条、设置菜单、弹幕（Canvas/DOM）、外挂字幕**均 100% 保持原生清晰，绝不出现白字变黑字或负片失真的情况；
- **多视频智能探针**：基于播放状态、显示面积与可视性智能识别主视频，精确跟踪小窗（Mini-player / PiP），自动排除缩略图悬浮预览和微型浮窗广告。

### 2. 🧠 智能白底课件自适应反色 (Auto Luminance Detection)
- **极轻量采样**：后台使用 $16 \times 16$ 离屏微缩 Canvas 进行高频抽检（默认 250ms 一次，可调 50 ~ 2000ms），**CPU 占用率极低**；
- **双特征精准判定**：
  - 统计像素高感知明度占比（$L = 0.299R + 0.587G + 0.114B > 210$）；
  - 统计色彩平均饱和度（$S_{avg} \le 22\%$）；
  - 判定白底课件后自动切换为柔和深色，切回暗景或真人实拍镜头时自动平滑恢复；
- **极致无感检测 (<0.01ms)**：采用降采样、整数位运算与早期剪枝优化，**单帧检测耗时仅约 0.002ms**（实测远优于 50ms 无感指标）；
- **退出迟滞缓冲 (Anti-Flicker)**：离开白底时需连续多次确认，杜绝转场高频频闪。

### 3. 🛠️ 开箱即用预设面板与高级折叠微调
- **点开即用极简界面**：打开参数设置面板，首先呈现的是最直观、免配置的「基础调色预设（柔和灰 / 纯黑）」与「浅色检测矩阵」；
- **🎨 专属色图拾色器**：内置原生可视化调色盘，可随意点选目标颜色并实时提取 HEX 色值，所选即所查；
- **⚙️ 高级参数折叠抽屉**：复杂的高级滑动条与数值框（亮度、对比度、饱和度、色相、切换速度、容差、明度线、采样周期等）整齐收纳在折叠抽屉中，既保持主界面清爽，又满足发烧友的极致精调需求。

### 4. 🤝 独创无对抗人机协同状态机 (Non-Conflicting HIL State Machine)
- **拒绝自动化“绑架用户”**：以往自动化脚本在误反色后，一旦用户手动调回，后台定时器下一秒又会擅自反弹改回；
- **场景指纹记忆**：当用户通过快捷键（`Alt+I`）或胶囊手动纠正时，脚本自动记录当前画面的“被否决场景特征”；
- **同场景不反弹**：只要视频画面仍属于该类型场景，自动检测器**绝对保持静默，绝不人机对抗**；仅当视频画面发生真实的场景剧变（如切入新章节或真人镜头）时，才重新接管。

### 5. 🖼️ 全浅色图表与矢量图智能反色 (Smart Image Invert - v1.4.0 深度升级)
- **多谱段全浅色系检测**：告别“只能识别纯白”的局限，全面支持 **纯白 (#FFF)、纸质浅灰 (#F5F5F5)、米黄暖白/羊皮纸 (#FAF0E6)、冷调淡蓝 (#F0F8FF)** 等各类技术文档常见浅色背景；
- **预设浅色色卡一键启闭**：4 块直观高亮色卡，点击即可开启或禁用特定浅色分类；
- **超轻量 8×8 极速采样**：单张图片像素检测耗时仅约 **0.0007ms (0.7微秒)**，插件占用极低；
- **Canvas 跨域防污染隔离**：彻底重构采样流程，避免单张跨域图片污染 Canvas 导致后续检测全部失效；
- **解除 URL 误过滤**：彻底修复将 URL 中的 `thumb`、`header` 误认为缩略图而跳过的顽疾，维基百科/知乎等平台的缩略高清图均能精准反色；
- **Alt + 鼠标左键即时强制反色/复原**：任意图片或 SVG 图表均可通过 `Alt + 单击` 单独强制切换反色；
- **纯 CSS 悬停瞬时显原图**：鼠标 Hover 到反色图片上时，由原生硬件加速展示未反色的原图，移开鼠标恢复反色。

### 6. 💊 极简边缘悬浮胶囊与全局快捷键
- **隐形贴边小药丸**：平时呈微型半透明小条吸附在屏幕边缘（支持自由纵向拖拽与左右吸附）；
- **全屏自动隐身**：进入全屏播放时自动隐藏，绝不遮挡沉浸式全屏观影；
- **全局快捷键**：
  - `Alt + I`：快速切换视频反色（带有人工覆盖意图保护）；
  - `Alt + A`：快速开启 / 关闭智能自适应感知模式；
  - `Alt + 鼠标左键`：强制切换网页任意单张图片或 SVG 反色 / 复原。
  - （v5.0 新增）：`Alt+Shift+点击` 元素屏蔽 · `Alt+M` 元素遮罩 · `Alt+Shift+Z` 恢复全部临时屏蔽
    · `Shift+悬停` 永久解除遮罩 —— 详见下方 v5.0 章节。

## 🧪 v6.0 开发中 (自动部分反色 · 内核已落地)

> **当前状态：内核已落地并冻结契约，但整套功能默认关闭、且本阶段不改变任何 DOM 观感。**
> 也就是说：装了这个版本的插件，你**看不到任何变化** —— 渲染层（v6-2）还没做。

要解决的问题：一张图里既有该反色的浅底、又有不该动的彩色内容时，**整图反色两边都错**。
白底 PPT 里嵌一张彩色照片 / 二维码 / 品牌 logo，整图反色会把照片变成负片。

v6.0 的第一片把**判定单位从整图下沉到连通区域**，并冻结了区域掩码契约
（[`RegionMask`](.trellis/spec/frontend/region-mask-contract.md)，v6-2 渲染 / v6-3 纠正只消费不重实现）：

- **零新依赖、零 ML、零网络**：判别信号完全复用现有两个特征（感知明度占比 + 平均饱和度），
  只是从「全图统计一次」变成「分块统计 N 次」（N 默认 16，可调 8~32）。
- **默认方向是「挖掉不该反色的区域」**，不是「找该反色的区域」—— 后者会把白底黑字之间的
  白缝判成独立区块，产出碎裂掩码。
- **形态学尾治理**：先用 3×3 开运算当**厚度门**（1~2 格厚的细笔划一律不算特征块，
  所以纯文字幻灯片会整图反色、文字变白可读），再闭运算填小洞；最小面积门 3%
  （不足面积的块跟随邻域多数，不为一个小白点把按钮挖出来）。
- **双性能门**：整图浅色占比 ≥ 97% 或 ≤ 3% 的图**零分割开销**，直接走原有整图路径；
  抠完又退回两端同样不挂掩码层。实测单图掩码构建 ≈0.04ms（N=16 典型路径）。
- **读不到像素必放行**：跨域 / 解码失败 / 全透明 → 不分割、不挂掩码，退化为整图判定，
  降级原因可在诊断里看到（`taint` / `decode` / `cross-origin` / `no-pixels` / `budget`）。
- **掩码按图缓存**（LRU 200，键 = 站点 + 元素词干 + 固有尺寸），同图重复出现零重复计算。

开关 `regionSegment` **默认关闭**；关闭时与 v5.0.0 行为完全一致（29 个浏览器端到端场景零回归）。
面板上的只读诊断行（分割次数 / 平均耗时 / 降级次数分原因 / 缓存命中率）随 v6.0 的 UI 重构一并交付。

## 🆕 v5.0 重大升级 (页面媒体治理层 · 动作统一)

> v5.0 把插件从「反色器」扩展为**通用页面媒体治理层**：一套统一的元素动作表，一套统一的
> 决策优先级链，一套统一的开关矩阵。**所有新动作默认关闭** —— 不开启时行为与 v4.6.1 完全一致。

### 1. 🧩 统一元素动作表 (Action Registry)

六种元素动作共用**一个**解析入口与**一个**写点仲裁，不再各引擎各写一套优先级：

| 动作 | 作用 | 默认 |
| :--- | :--- | :--- |
| `invert` | 反色（现状主路径） | 开 |
| `keep` | 保持原样 | 开 |
| `bgInvert` | 背景图反色 | 开 |
| `hide` | 元素屏蔽 | **关** |
| `mask` | 遮罩 | **关** |
| `dim` | 全页压暗 | **关** |
| `peek` | 悬停复原通用门（与既有「悬停显示原图」同一开关） | 开 |

> 真实优先级链（**不是**一条直线）：
> `手动 > 用户元素规则 > 【决策快照】 > 学习规则 > 种子保护 > favicon跳过 > 种子强制反色 > 像素`
> —— 决策快照卡在中间，位置不可移动；这正是 v5.0 重构时逐字保真的地方。

### 2. 🚫 元素屏蔽 (hide)

- `Alt+Shift+点击` 屏蔽该元素：**首次 = 临时**（仅本会话，刷新即恢复），**再点 = 恢复**，
  **第三次 = 永久**（写入学习规则，同结构元素此后自动屏蔽）；
- `Alt+Shift+Z` 一键恢复本页全部临时屏蔽；
- 屏蔽用 `display:none`（不占位），因此**不提供悬停窥视** —— 不可悬停的东西没法悬停揭示。

### 3. 🌫 遮罩 (mask) — 三档风格可调

- `Alt+M` 给**鼠标所在元素**加/取消遮罩；面板「🧩 元素动作」有「区域遮罩（拖拽）」按钮
  （一次性武装，拖拽框选，`Esc` 取消）；
- **三档预设**（面板可切，参数可调）：

  | 预设 | 效果 | 不透明度 | 悬停后 |
  | :--- | :--- | :--- | :--- |
  | 暗色半透明 | 压暗但保留轮廓 | 0.75 | 0.15 |
  | 全遮挡 | 完全盖住 | 1.0 | 0.15 |
  | 毛玻璃 | 模糊化，保留色块与布局感 | 0.35 | 0.05 |

- **可移动鼠标解除**：鼠标移入遮罩 → 自动揭开（降到可调的不透明度）；移出 → 恢复；
  **`Shift` + 移入 = 永久解除**该遮罩；
- 实现走 `::after` 伪元素（零 DOM 节点、随元素滚动/变形天然跟随、无 z-index 战争）。
  **若元素 `::after` 已被站点占用，则跳过该元素的遮罩并提示** —— 本项目不往站点元素里
  塞子节点（会破坏站点的 `:first-child` / `childNodes` 假设）。

### 4. 🌑 全页压暗 (dim)

整页盖一层压暗蒙层（`pointer-events:none`，不拦点击），比反色温和，**不改内容颜色**。
不透明度可调（0 ~ 0.9），鼠标移入可临时揭开。

### 5. 🔌 开关矩阵与安全模式

- 每个动作**一行开关 + 作用域 + 生效时机**，全部集中在「🧩 元素动作」区块；
- 关闭某动作会**立即拆除本页所有对应标记**（开关即回滚，不需要刷新）；
- 一键「安全模式（只留反色）」把所有会改动页面观感的动作全关。

### 6. ⌨️ 新增快捷键

| 快捷键 | 作用 |
| :--- | :--- |
| `Alt+Shift+点击` | 屏蔽 / 恢复该元素（三态循环，见上） |
| `Alt+M` | 给鼠标所在元素加 / 取消遮罩 |
| `Alt+Shift+Z` | 恢复本页全部临时屏蔽元素 |
| `Alt+Z` | 撤销最近一次**自动**结论（可连按继续回退） |
| `Shift+悬停遮罩` | 永久解除该遮罩 |
| `Esc` | 取消区域遮罩的武装态（不影响原有关闭弹窗行为） |

### 7. ↩️ 复查与撤销（错了不用再回到页面上找）

**痛点**：自动反色不可能 100% 正确。以往一旦反错，你只能回到页面上把那张图找出来再点一次。

- **`Alt+Z` 逐个撤销**：撤销最近一次**自动**结论（可连按继续回退，默认保留 30 步，仅内存）；
- **批量提示条**：一次处理 ≥3 个元素时弹一条带「撤销」按钮的提示，一键全部回退
  （单张不弹提示，避免变成噪音 —— 单张回退用 `Alt+Z`）；
- **「本页已处理」列表**（设置 → 🖼️ 当前页媒体 / 已处理）：列的是**脚本这次改了什么**
  —— 缩略信息 + 选择器 + **原因码**（像素判定 / 学习规则 / 种子保护 / 遮罩否决 / …）+ 时刻，
  每项可 **还原 / 定位 / 固化**；「全部还原」一键回退撤销栈内全部。
  旁边的「🗂 全部媒体」是 v3.1 的原始视图（页面上有什么），行为不变；
- **一键固化**：列表项点「固化」把这次结论写成本站规则并**立即生效**（不必再点 2 次）。
  另有「本站不自动反色图片」一键关闭本站的图片自动反色；
- **撤销是持久的**：撤销 = 摘标记 + 清缓存 + 落一条「用户否决」结论（与 Alt+点击还原同语义），
  因此下一次扫描不会把同一个错误结论又推回来。手动结论始终占优，撤销不会推翻你自己点过的结果。

### 8. 🩺 误反哨兵

记录你的手动修正：同一张图 24h 内被还原 2 次 → 提示「这张图已按你的历史修正保持原色」；
同一类元素被还原 3 次 → 提示「可在『本页已处理』里一键固化」。
**只记录与提示，不自动写规则** —— 自动写规则会把一次点击放大成永久决定。

### 9. 🔒 撤销栈的边界（刻意如此）

- **仅内存**：刷新即清空，不落盘（与标签页隔离纪律一致）；
- **只记自动结论**：你手动 `Alt+点击` / `Alt+Shift+点击` / `Alt+M` 的结果不入栈
  —— 提供「撤销你自己」没有语义；
- **只记有可见状态的结论**：被判定为"保持原样"或"跳过"的元素不入栈（没有东西可回退）。

### 10. 📊 数据闭环（采集到的数据真的被用上）

此前采集了四份数据却几乎没有回读路径。v5.0 把「用上」的部分补齐：

| 数据 | 现在怎么被用上 |
| :--- | :--- |
| **学习规则的命中数** | **分级**：命中 ≥ 强规则门（默认 5）= 强规则（保持现有优先级）；已生效但未达门 = 弱规则，只能覆盖像素判定、**不再压过内置种子规则**。列表里直接显示「强规则 / 弱规则 / 已降级禁用」 |
| **你的手动修正** | **负反馈降级**：规则命中后被你手动覆盖 → 该规则命中数归 1；连续 2 次被覆盖 → 自动禁用（列表里可点「恢复」） |
| **误反/误保计数** | **阈值自校准**：误反占比超阈且样本足够 → **自动收紧**本站判定阈值（减少误反）；放松只给建议、需你点按钮。面板可一键「恢复本站默认阈值」 |
| **元素形状** | **跨站先验**：某「元素长相」在 ≥N 个不同站点上结论一致时，对新站同形元素给出最弱先验。**默认关** |
| **判定来源** | 面板显示「本页判定来源：12 项 · 像素判定×9 / 学习规则×2 / …」，一眼看出哪条路径在起作用 |
| **你的修正 → CI** | `node scripts/export-fixtures.js <导出的备份.json>` 把你的结论转成 `dev/fixtures/verdicts.jsonl`，`node test.js` 会多跑一组断言 —— 代码改动若破坏了你积累的判断，测试立刻失败 |

**关于「hits 分级」默认关**：开启会改变既有学习规则的优先级（弱规则不再压过种子规则），
属行为变更，所以由你显式选择。

**关于「只自动收紧」**：两侧风险不对称 —— 收紧错了只是少反几张（你还能 Alt+点击），
放松错了会在你没要求时把东西反过来。本项目一贯避免后者。

### 11. 🔒 隐私底线（数据闭环没有破坏它）

- **零新增联网**：网络出口代码与 v4.6.1 **逐条一致**（`fetch` 3 处，无 `XMLHttpRequest`、
  无 `navigator.onLine`），本版本新增的一切数据处理都在本地完成；
- **导出仍是显式动作**：规则包 / 备份 / fixture 都只有你点了才会产生；
- **fixture 不入库**：`dev/fixtures/` 已 gitignore —— 它含你自己的图片 URL，属个人数据。

### 12. ⏱ 提前判定（视频帧序列 · 动图全帧谱）

**视频**：判定从"单帧判"升级为**帧序列判**（最近 3 帧滑动窗），加两个门：

| 门 | 触发 | 效果 |
| :--- | :--- | :--- |
| **提前切换** | 从阈值下方明确跃变上来（跃变 ≥ 场景跃变门） | 不等下一帧确认就判白 —— 感知上"场景一变，颜色已经对了" |
| **转场白闪不切换** | 刚过阈值、窗口内孤立的一帧白、且无明确跃变 | 判为转场闪光，**不触发反色**（不再一闪一闪） |

> 两个门的优先级是：**明确跃变优先**。因为"暗→白的真实场景切换"与"转场白闪"在只看当前帧时
> 形态相同，只能靠跃变幅度区分 —— 这条在实现时纠正过一次（初版把真切换也压掉了）。

两条采样路径（rVFC 逐帧 / 250ms 兜底轮询）**共用同一个判定函数**，避免两路切换时结论抖动。
关闭「帧序列判定」即回到 v4.6 的单帧判语义。

**动图（GIF / 动画 WebP / APNG / AVIF）**：此前动图只按**一帧**判死，换景后会一直错。现在：

1. **廉价闸门**：后缀/类型命中，或两个时刻采样不同 → 疑似动图；
2. 命中才付代价：用 `ImageDecoder` 解出**全部（等间隔抽样）帧**算亮度谱；
3. **三分类**：全浅 → 反色；全深 → 保持原样；**混合型 → 默认保持原样**。

> **混合型为什么默认不反**：CSS 滤镜**无法按时序切换**。要真的逐帧反色得把 GIF 交给 canvas
> 逐帧重绘（成本高、跨域受限）。所以默认保守；「按多数帧近似」只是一个选项，面板里
> **如实标注它不是逐帧切换** —— 不假装能做到。

- 双预算：帧上限（超出按 `stride` **等间隔抽帧**，不是只解开头几帧 —— 那会系统性偏向"开头白底"的 GIF）
  + 毫秒上限（超限用已解帧出结论）；
- 动图结论**允许有界复议一次**（默认 30s 后）—— 它是唯一"同一 src 不同时刻答案可能不同"的媒体；
- 环境不支持 `ImageDecoder` → **静默降级**为静态判定并在面板说明一行，绝不报错。

### 13. 🛡 加载前保护（三档 + 元素遮罩）

解决了"先看到刺眼的纯白图、过几十毫秒才被反色"这一下白闪。原「防闪光黑底」升级为**三档**：

| 档 | 行为 |
| :--- | :--- |
| 关闭 | 零介入 |
| **文档黑底**（默认） | 深色站点加载前先铺黑底（与 v4.6 行为**完全一致**） |
| 文档黑底 + 元素遮罩 | 另对「本站已知会反色」时的**新插入媒体**先遮住，判定完成即放行 |

> **⚠ 形态能力边界（必须知道）**：真正的"首帧前遮罩"**只有扩展形态做得到**（`document_start`）。
> 用户脚本在 `document-end` 启动，**首屏元素已经渲染过了** —— 所以元素遮罩只覆盖
> **脚本启动之后动态插入的元素**，首屏由文档黑底兜底。面板里写明了这一点，不假装能全做到。

**触发门（不会无条件遮）**：只在"本站已知会反色"时启用 —— 内置强制反色规则 / 本站有学习到的
反色规则 / **上次本站反色率 ≥ 35% 且样本 ≥ 5** / 你在面板里强制启用。
**首访站点一律不遮** —— 宁可白闪一次，也不白藏你的图。

**绝不伤人**（三道保险）：

- **三层预算**：总时长（默认 1.2s）/ 元素数（默认 80）/ 单元素超时（默认 0.8s），
  任一超限立即放行；
- **判定失败必放行**：拿不到像素、跨域失败、分析异常 → **立即摘罩显示原图**，
  绝不允许"拿不到像素就把图藏起来"；
- **逃生**：有东西被遮住时按 `Esc`，或点面板「立即显示全部（并暂停本会话）」——
  一次性放行并**本会话不再遮罩**。

元素遮罩的门是**纯 CSS 属性门**（`visibility:hidden`），判定完成即自动失效 ——
全程不动站点的 DOM 结构、不写 inline style。

**升级说明**：旧布尔开关 `flashGuard` 会自动迁移（`true` → 文档黑底、`false` → 关闭），
并按新档位同步写回，因此回退到旧版本仍能读到正确的值。

### 2. 🎛️ 智能图片策略 (决定"什么时候该反色")
- 新增 `imagePolicy` 三档策略（✨效果 板块可切换），默认 **平衡 (balanced)**：
  - **平衡**：正文上下文（`.markdown-body`、文章/评论区等）**或**（渲染尺寸 ≥ 96px **且** 非网格重复 **且** 非页面骨架上下文）才反色；
  - **保守**：仅正文上下文或 ≥ 200px 大图；
  - **激进**：v3.0 行为（仅尺寸门）。
- **网格重复启发式**：同一父容器内 ≥ 4 个同尺寸同标签图片 → 判定为封面/贴图网格，一律跳过——B 站首页/视频页的浅色封面墙**无需手写规则**即可保持原样，而正文里的孤立白底大图照常反色；
- **页面骨架上下文**：`nav/header/aside/footer`、卡片/封面类名（`card`/`cover`）、单图链接锚（`a>img`）中的图片不再自动反色；
- 优先级不变：**手动 Alt+点击 > 自学习规则 > 种子强制反色/保护 > 策略门 > 像素分析**——种子强制反色（如 GitHub markdown/camo）与保护选择器完全绕过策略门。

### 3. 🔁 GitHub / 长页面首屏即刻反色 + 统一决策管线
- **eager 初始处理**：启动时已加载完成的图片不再等待视口交叉（不再依赖滚动触发），预算内（默认 80 张，可调）立即决策——打开 GitHub README **不滚动首屏即全部反色**；启动后 2.5s / 6s / 12s 三轮补扫覆盖晚完成的加载；
- **统一决策管线 (decide-once)**：全部处理入口（视口交叉 / 动态插入 / eager / 手动重扫）收口到唯一决策函数，优先级严格有序；同一图片的最终决策只算一次并缓存（按 src 决策快照），**相同输入永不出现"第一遍不反色、滚一遍又反色"的反复横跳**；重新评估仅经显式重扫（设置变更/手动触发）；
- **决策后标记**：`data-svi-checked-src` 只在决策达成后写入；分析失败 60s TTL 内静默、最多重试 3 次后永久跳过并记录原因；同 src 新增元素命中决策缓存时**同步应用**（放大镜覆盖层瞬时反色的基础）。

### 4. 🌗 悬停显示原图开关
- 🌙基础 板块新增「悬停显示原图」（默认开，保持 v3.0 行为）：关闭后，鼠标悬停已反色图片**保持反色视图**（CSS 滤镜路径与特效 `content:url` 路径双双生效），适合不喜欢"一碰就闪原图"的场景。

### 5. 🔍 放大镜 / 看图类浏览器插件适配 (浮图秀等)
- `Alt+点击` 改经 `event.composedPath()` 解析目标：**Shadow DOM（含闭合根）内的媒体也可切换反色**；
- 动态插入的媒体若其 src 已有决策缓存，变更扫描**同步应用决策**——放大镜浮层中"已看过的图"瞬时反色，无需等待；
- 背景图引擎覆盖 body 末尾动态追加的覆盖层元素（`inline style background-image`）。

### 6. 🩺 GitHub 不生效排查 (FAQ)
若在 GitHub README 上感觉脚本"没生效"，请依次检查：
1. **确认脚本版本**：打开油猴管理面板，确认「全网通用智能视频与图片反色」版本号为 **3.1.0** 或更高（旧版存在首屏不反色与封面横跳问题）；
2. **自动更新静默失败**：脚本经 `raw.githubusercontent.com` 检查更新——若你的网络访问 GitHub Raw 失败（或旧版脚本指向的仓库已私有/更名，Raw 404），油猴会**静默保留旧版本**。解决：在油猴面板「实用工具 → 检查用户脚本更新」手动触发，或直接重新点击上方安装链接覆盖安装；
3. **检查脚本是否被禁用**：油猴图标数字角标是否点亮、本站是否被黑名单/白名单或"本站启用"开关关闭；
4. **状态自检**：设置弹窗 →「🖼️ 当前页媒体」→ 采集列表，若图片状态为"跳过:…"，原因一目了然（也可顺手在此手动反色）。
